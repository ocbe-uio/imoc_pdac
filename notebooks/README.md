# Notebooks
This folder contains all Jupyter notebooks, as well as the file `general_functions.py`, containing functions required in all scripts.
* `data_preprocessing`: script containing data pre-processing steps for each modality, upset plot and overall survival and disease-free plots for all patients.
* `first_benchmark_analysis`: analysis of results from first benchmark (testing best combination of modalities and number of clusters).
* `second_benchmark_analysis`: analysis of results from second benchmark (testing best algorithm).
* `final_clusters_analysis`: final clusters obtained, consensus analysis and differences in molecular expression between groups.
* `papers_clusters_analysis`: comparison of clusters identified with three (Collisson, Moffitt, Bailey).
* `survival_clinical_analysis`: survival and disease-free analyses, as well as enrichment of various clinical labels.
* `biomarker_analysis`: identification of potential copy number and methylation biomarkers.
*`shapiq_analysis`: analysis using Shapley Interactions.
